# Mycorrhiza protocols

A collection of laboratory and field notes on arbuscular mycorrhizal fungi (AMF), covering sampling, spore extraction, root staining, cultivation, microscopy and assessment of colonization.

This repository organizes the supplied document **protocolos Micorrizas.docx** for consultation and collaborative review. All documentation is in English. Portuguese and Spanish passages have been translated; passages already in English have been retained. Scientific names, numerical values, alternative conditions and unresolved details have been preserved.

**Documentation status:** organized draft pending technical review. Several formulations and procedures contain missing information or unresolved alternatives. Read the review notes on each page before treating it as a complete procedure.

## Using this collection

1. Select a topic and read its items requiring confirmation.
2. Identify the appropriate variant with the technical lead and record its version.
3. Use the recording templates to document the actual experimental conditions.
4. Support proposed corrections with a source and an explanation.

## Provenance and attribution

Prepared from the document supplied by the collection’s custodians. Authors, institution, contact details and full bibliographic references remain to be provided. Existing English passages and their attributions have been retained for verification; their origin and reproduction permissions require confirmation before publication.

Editorial headings and review notes were added during organization. Missing values were not supplied by inference, and different protocol variants were not combined. Translation does not constitute experimental validation.
